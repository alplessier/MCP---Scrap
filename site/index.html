Envoyer au panier Carrefour

Un site extérieur ne peut pas remplir votre panier : c'est une protection du navigateur. Un petit script, installé une seule fois, fait l'ajout sur carrefour.fr, dans votre compte. Les produits apparaissent ensuite aussi dans l'application Carrefour.

Option 1 — Automatique (recommandé)

  1. Installez l'extension gratuite Violentmonkey ou Tampermonkey (Chrome, Firefox, Edge, Firefox Android ; sur iPhone : l'app « Userscripts » pour Safari).
  2. Installer le script « Panier Carrefour », puis confirmez dans l'extension.

Ensuite, un clic suffit : carrefour.fr s'ouvre et remplit le panier.

Option 2 — Sans extension, avec un favori

Glissez ce bouton dans votre barre de favoris : 🛒 Panier recette

Après chaque envoi, cliquez sur ce favori une fois la page Carrefour ouverte.

Connectez-vous à votre compte sur carrefour.fr dans ce navigateur pour retrouver le panier dans l'application. Les quantités s'ajoutent à ce qui est déjà au panier.
