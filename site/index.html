Envoyer au panier Carrefour

Deux façons de faire. Le panier est celui de votre compte : il apparaît aussi dans l'application Carrefour.

📋 Liste guidée — sans rien installer

Chaque produit s'ouvre sur carrefour.fr (ou dans l'application sur mobile) : vous l'ajoutez d'un geste et le cochez.

⚡ Tout ajouter en un clic — à installer une seule fois

Une fois installé, le site le détecte : le bouton ouvre directement Carrefour et remplit le panier, sans cette fenêtre.

Autre option sur ordinateur : un favori, sans extension

Glissez ce bouton dans votre barre de favoris : 🛒 Panier recette

Après chaque envoi, cliquez sur ce favori une fois la page Carrefour ouverte.
